Acessibilidade desta versão

Esta é uma versão corrigida, para pesquisa, da página oficial (OBM - Olimpíada Brasileira de Matemática). Não é o site oficial e não é atualizada.

Meta

Critérios de nível A e AA das Diretrizes de Acessibilidade para Conteúdo Web (WCAG) 2.2 e art. 63 da Lei Brasileira de Inclusão, mantendo o visual original.

Correções aplicadas

  • scripts do original removidos (20); links e recursos relativos tornados absolutos
  • viewport sem bloqueio de zoom
  • link "Ir para o conteúdo" como primeiro elemento
  • título da página identifica que é a página inicial (1×)
  • desenho em <canvas> feito por JavaScript (vazio sem script) removido (1×)
  • logotipo (único conteúdo do link) com texto alternativo (1×)
  • campo de busca com rótulo (placeholder não é rótulo) (1×)
  • botão de imagem da busca com texto alternativo (1×)
  • ícone do Facebook no topo ganha nome (1×)
  • atributo title igual ao texto do link removido (6×)
  • <div class="header-main"> fechado antes do fim do cabeçalho (HTML válido) (1×)
  • descrições de submenu (só visuais) não repetidas ao leitor de tela (17×)
  • conteúdo dentro de <main>, com h1 (visualmente oculto: o original não tem título visível) (1×)
  • fim do <main> (1×)
  • títulos de seção (Novidades, Calendário, Destaques) viram h2 (3×)
  • títulos dos cartões viram h3 (8×)
  • sinal "+" decorativo escondido do leitor de tela (8×)
  • botão "≡" (só funcionava com JavaScript) vira link para o menu, que abre sem script (1×)
  • links "Saiba mais" dos banners com o assunto em texto oculto (2×)
  • itens do calendário deixam de ser links "#" sem destino (5×)
  • logotipos de parceiros (únicos conteúdos dos links) com o nome da instituição (4×)
  • link "Tel" sem número removido (1×)
  • e-mail que só aparecia com JavaScript passa a ser texto (1×)
  • link de e-mail vazio removido (1×)
  • ícone "icon-facebook" ganha nome (1×)
  • ícone "icon-instagram" ganha nome (1×)
  • ícone "icon-youtube" ganha nome (1×)
  • fechamentos de tag sem abertura removidos, herdados do original (1×; HTML válido)
  • símbolo e página de acessibilidade, link para o original e aviso no rodapé

Avaliação

A verificação é feita com ASES, WAVE e Lighthouse e por inspeção manual (UFC Quixadá, 2026).
